# §4 Exploratory Feature Analysis — 中文逐段解釋

對應檔案：`report/p2_section4.tex`。每一段說明「這段在講什麼」、「數字從哪裡來」、「口頭報告時可以怎麼說」。

## 開頭段：分析範圍與統計方法

**在講什麼**：本節只用訓練集（972 筆正常、104 筆病理，來自 175 次檢查），沒有看驗證集和測試集。標籤只用來描述分布，one-class 模型仍然只用正常資料訓練。

**為什麼要提 exam-level bootstrap**：104 筆病理片段只來自 28 次檢查，其中兩次檢查就佔了 36 筆。同一次檢查的片段彼此很像，如果把 104 筆當成 104 個獨立樣本，信賴區間會太窄、結論會太有自信。所以我們重抽的單位是「整次檢查」而不是「單一片段」。

**數字來源**：`EDA/outputs/audit_train.json`。

## Distribution contrast（分布比較）

**在講什麼**：
1. ASTV（短期變異度異常的時間比例）在病理片段明顯較高：中位數 40 → 65。
2. MLTV（長期變異度平均值）在病理片段往 0 集中：51% 的病理片段是 0，正常只有 4%。
3. MSTV 在病理片段是**雙峰**的，有一群很低、一群很高。
4. 先選出病理片段，再依「有沒有延長減速（DP > 0）」分成兩個描述性子群，就能解釋雙峰：
   - DP-present（65 筆）：MSTV 高（2.7）、直方圖很寬（113）、平均心率被拉低（96 bpm）。
   - DP-absent（39 筆）：MSTV 極低（0.3）、直方圖很窄（18）、ALTV 很高（69%）。
   - 這個分組用到了 Pathologic 標籤，是對訓練資料的描述，不是臨床病理分型。
   - 兩群往**相反方向**偏離正常；只有 ASTV 兩群都偏高。
5. 事件型特徵有大量 0，所以改比「有沒有出現」：延長減速 62.5% 對 4.7%；加速 19.2% 對 67.2%。

**白話**：訓練集的病理片段在數值上有兩種樣貌，一種曲線很平，一種有延長減速且起伏大。兩者在很多特徵上方向相反，所以把病理當成一個整體去算平均或相關係數，會互相抵銷。

**圖**：Figure 1（`fig1_variability_contrast`）。上排是各類別自己加總為 1 的直方圖（避免 972 對 104 的不平衡讓病理那條看不見），下排是累積分布（ECDF），黑色直線標出兩條線最大的垂直距離，也就是 KS。X 軸涵蓋完整的資料範圍，沒有截尾。逐步讀圖教學見 `p2_eli5_learning_path_zh.md` 第 2 章。

**數字來源**：`separability.csv`、`pathologic_phenotypes.csv`、`event_presence.csv`。

## Feature separability（特徵可分性）

**在講什麼**：
- 三種量化指標：KS（兩個分布累積曲線的最大差距，0 到 1）、AUC（隨機抽一筆病理和一筆正常，病理的值比較大的機率；離 0.5 越遠越能分開，小於 0.5 代表病理的值比較小）、Mutual Information（知道這個特徵後，對標籤的不確定性減少多少）。
- Wasserstein distance 會受單位影響，所以先除以正常資料的標準差再比較，不直接拿原始數值排序。
- **ASTV 最強也最穩**：KS 0.71，區間 0.56–0.83。
- **DP 和 Mean 看起來強，但不穩**：區間很寬，而且拿掉兩個最大的病理檢查後，KS 從 0.60／0.58 掉到 0.41／0.37。也就是說它們的強度有一部分是少數幾次檢查貢獻的。
- 如果用一般的（以片段為單位的）bootstrap，DP 的區間會是 0.51–0.68，明顯低估不確定性。這是我們堅持用 exam-level 的理由。
- **MSTV 的教訓**：單向 AUC 只有 0.59（看起來沒用），但改看「離正常平均多遠」（|z| 的 AUC）是 0.80。對異常偵測來說，重要的是偏離程度，不是偏離方向。
- LB（基準心率）單獨沒有用（0.37，比亂猜還差，代表病理片段的 LB 反而更集中在正常中心附近）。

**表**：Table 1 選了 8 個特徵；完整 21 個在 `EDA/outputs/separability.csv`。

**可能被問**：「KS 可以用在有很多 0 的離散特徵嗎？」——KS 統計量本身仍是兩條累積曲線的距離，可以當描述性指標；不適用的是它的 p-value（假設連續分布），所以我們不報 p-value，改用 bootstrap 區間，並對事件型特徵另外報出現率。

## Redundancy（冗餘）

**在講什麼**：
- `Width = Max − Min` 在訓練集每一筆都**完全相等**（不是高度相關，是恆等式），所以 21 個特徵實際只有 20 個自由度。
- Mode、Mean、Median 幾乎可以互換（ρ 0.90–0.97）；Width、Min、Variance 也高度相關。
- 相反地，四個變異度特徵彼此**不**冗餘（ASTV–MSTV ρ = −0.36；ALTV–MLTV ρ = −0.02）。原本擔心 ASTV／MSTV、ALTV／MLTV 是重複資訊，資料不支持這個擔心。
- 挑選規則只用正常訓練資料、不使用異常標籤：先移除 Width，再把其餘 Histogram 特徵依 |ρ| ≥ 0.8 分群，每群留最有代表性的一個。結果移除 Width、Mode、Mean，剩 18 個特徵（PRUNED18，R5 起的主要定義）。
- **這不是無損精簡。** 只移除 Width 才是無損（它可由 Max、Min 算回）。Mode、Mean 與 Median 高度相關但不相同；留下的 18 個特徵線性解釋它們變異的 93%、94%。所以論文寫的是 “heuristic”，並另外設一組只移除 Width 的 20 特徵對照。較早的 17 特徵版本（另外移除 Min）只保留為選做對照。

**為什麼強調「不使用異常標籤」**：如果用病理標籤挑特徵，就不能再說模型流程沒有用到異常標籤。這個規則只用正常資料，和 one-class 的設定一致。

**數字來源**：`redundancy_pairs.csv`、`vif_normal_train.csv`、`histogram_pruning.json`；圖在 `fig4_spearman_heatmap`（版面不夠可放附錄或簡報）。

## Exploratory hypotheses（探索性假說）

**在講什麼**：因為兩個子群分別在不同的特徵群上偏離正常，所以消融以「特徵群」為單位，而不是一次拿掉一個特徵。

- **H1**：變異度特徵群提供其他特徵補不上的偵測資訊。預期拿掉後表現下降，主要影響沒有延長減速的病理片段。這是待驗證的猜想，論文沒有寫「必要」。
- **補充觀察（R5 起不再編號為假說，論文中以一句負面結果交代）**：減速的「類型」有資訊。把 DL、DS、DP 加總並不會更好，因為輕度減速在正常片段就很常見（45%），加總後 KS 從 0.60（只看 DP）掉到 0.40。這段如實寫出**我們原本的預期沒有被支持**。
- **H3**：依正常資料相關性挑選的 18 個特徵，偵測表現與 21 個相近。對照組是只移除 Width 的 20 個特徵。論文明講這個挑選不是無損的，結果要由實驗決定。

最後一句交代實驗控制：只改特徵集合，資料切分、模型設定、seed 都固定，以驗證集的 PR-AUC 判斷。

**沒有寫進論文、但已經做了的東西**：我們另外做了一個只用訓練集的探索性探針（Mahalanobis 距離＋exam 分組交叉驗證），結果與三個假說的方向一致（見 `p2_hypotheses.md`）。它沒有放進 §4，原因有兩個：那已經是「模型結果」，容易和 §7–§8 的正式實驗混淆；而且它用了訓練集的異常標籤評分，不能當成無監督的證據。請不要把它的數字寫進論文。
