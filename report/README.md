# 書面報告

本資料夾存放整合後的論文原始檔、引用資料與最終 PDF。

整合負責角色：I1

## 章節分工

- P1：第 3 節，任務定義與資料
- P2：第 4 節，探索式特徵分析
- P3：第 5 節，方法
- P4：第 6 節，實驗設定；第 7 節，主要結果
- P5：第 7 節，消融結果；第 8 節，分析
- W1：摘要、第 1 節緒論、第 2 節相關研究、第 9 節結論與限制，以及參考文獻
- I1：整合、排版、成員貢獻與工具使用說明

## 協作方式

大家先在共用的 Google 文件完成各自章節，附上圖表與文獻來源。
內容確認後，由 I1 整理到 Overleaf，完成排版並匯出 PDF。

## 格式要求

- 使用指定的 ACL 論文格式
- 最多 6 頁，成員貢獻計入頁數，參考文獻另計
- 首頁標題下方放專案的 GitHub 連結
- 圖表需有編號、說明，並在正文中引用
