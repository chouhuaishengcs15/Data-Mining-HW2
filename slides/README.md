# 口頭報告簡報

本資料夾存放整合後的簡報檔案。

整合負責角色：I1

## 主題分工

- P1：資料來源、異常定義與資料切分
- P2：資料分布、特徵分析與主要觀察
- P3：主要方法、流程圖、異常分數與判定門檻
- P4：評估方式、三種方法比較與運算成本
- P5：消融結果、錯誤案例、模型解釋與實際影響
- W1：研究動機、相關研究、結論與限制
- I1：封面、成員分工、整體順序與版面整合

## 協作方式

大家在共用的 Google 簡報製作自己負責的主題，再由 I1 整合。

## 報告要求

- 每組口頭報告 8 分鐘
- 簡報沒有規定頁數
- 繳交格式為 PPTX 或 PDF
- 上台使用繳交的版本
